# Build a RAG system

Retrieval-augmented answering over a store's policy documents, as 26 small functions on a real embedding model and a real chat model: chunk, embed, search by meaning and by keyword, cite, abstain, and check every sentence.

Built step by step on [Deep-Agnt](https://deep-agnt.com/projects/rag-system): 12 of 26 steps passed, each graded by tests.

- [x] Step 1: Split a document into paragraphs
- [x] Step 2: Pack paragraphs into chunks
- [x] Step 3: Chunk every document
- [x] Step 4: Cosine similarity
- [x] Step 5: Embed a batch in one call
- [x] Step 6: Build the index
- [x] Step 7: The nearest chunks
- [x] Step 8: Search by meaning
- [x] Step 9: The words of a text
- [x] Step 10: Rank by shared words
- [x] Step 11: Fuse rankings
- [x] Step 12: Hybrid search
